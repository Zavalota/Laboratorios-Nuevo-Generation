Quiénes Somos

¿Qué hace nuestro grupo?

Somos un equipo de desarrolladores de software en formación, especializados en Ingeniería en Tecnologías de la Información. Nuestra pasión es explorar las últimas tendencias tecnológicas, desde el desarrollo backend con lenguajes como Java y Python, hasta el despliegue de infraestructura en la nube e integración de herramientas de Inteligencia Artificial.

¿Por qué existe este sitio web?

Este sitio web fue desarrollado como parte de un proyecto práctico bajo la metodología ágil SCRUM. Existe con el propósito de aplicar y consolidar nuestras habilidades en el diseño de interfaces web, control de versiones con GitHub y trabajo colaborativo, con miras a fortalecer nuestro portafolio para la transición a roles de infraestructura y desarrollo cloud.
